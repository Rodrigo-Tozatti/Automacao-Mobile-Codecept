================================================================================
ANDROID STUDIO - INSTALAÇÃO E CONFIGURAÇÃO PARA APPIUM (Apple Silicon M1/M2)
================================================================================

O QUE É O ANDROID STUDIO
--------------------------------------------------------------------------------
Android Studio é a IDE oficial do Google para desenvolvimento Android. No
contexto de automação com Appium, ele é necessário pelo Android SDK que
acompanha sua instalação, fornecendo as ferramentas ADB, emuladores (AVD)
e platform-tools que o Appium utiliza para se comunicar com os dispositivos.


⚠️  LEIA ANTES DE COMEÇAR
--------------------------------------------------------------------------------
  - NÃO baixe a versão Intel (x86_64). Para M1 e M2, baixe exclusivamente
    o arquivo .dmg Apple Silicon disponível na página oficial.
  - O caminho padrão do SDK no macOS é ~/Library/Android/sdk. Verifique
    o caminho real em: Android Studio → Settings → Android SDK → SDK Location.
    Se for diferente, ajuste as variáveis de ambiente conforme o caminho real.
  - Sem o ANDROID_HOME configurado, o Appium não consegue localizar o ADB
    e os testes Android não funcionarão.
  - Sempre execute source ~/.zshrc ou abra um novo terminal após editar
    o arquivo ~/.zshrc para que as variáveis sejam aplicadas.
  - Para M1/M2, selecione imagens de emulador com arquitetura ARM64 ou
    Apple Silicon. Imagens x86 não são compatíveis com Apple Silicon.
  - NÃO instale o Intel x86 Emulator Accelerator (HAXM) no M1/M2.
    O emulador usa ARM nativamente e o HAXM não é necessário.


DOWNLOAD E INSTALAÇÃO
--------------------------------------------------------------------------------
1. Acesse a página oficial:
   https://developer.android.com/studio

2. Clique em "Download Android Studio" e aceite os termos de uso.

3. Na página de download, selecione a versão correta para Apple Silicon:

   Mac com chip Apple (M1/M2) → arquivo .dmg Apple Silicon

4. Abra o arquivo .dmg baixado e arraste o Android Studio para Applications.

5. Abra o Android Studio pela pasta Applications.

6. Na tela de boas-vindas, siga o Setup Wizard:
   - Selecione "Standard" como tipo de instalação
   - Aceite as licenças dos componentes do SDK quando solicitado
   - Aguarde o download e instalação dos componentes iniciais


INSTALAÇÃO DOS COMPONENTES SDK (obrigatórios para o Appium)
--------------------------------------------------------------------------------
Após a instalação inicial, abra o SDK Manager:

  Android Studio → Settings → Languages & Frameworks → Android SDK

Na aba "SDK Platforms":
  ✔ Instale ao menos uma versão do Android SDK (recomendado: Android 13 ou 14)

Na aba "SDK Tools", marque e instale os seguintes itens:
  ✔ Android SDK Build-Tools
  ✔ Android SDK Command-line Tools (latest)
  ✔ Android Emulator
  ✔ Android SDK Platform-Tools


Clique em "Apply" e aguarde a conclusão do download.


CONFIGURAÇÃO DAS VARIÁVEIS DE AMBIENTE
--------------------------------------------------------------------------------
Edite o arquivo ~/.zshrc com o comando abaixo e adicione o bloco ao final
do arquivo. Consulte o documento VARIÁVEIS DE AMBIENTE para o passo a passo
detalhado de como editar o arquivo corretamente.

    nano ~/.zshrc

Bloco a ser adicionado ao final do arquivo:

    # ── Android SDK ───────────────────────────────────────────────────────────
    export ANDROID_HOME=$HOME/Library/Android/sdk
    export ANDROID_SDK_ROOT=$ANDROID_HOME
    export PATH=$ANDROID_HOME/tools:$ANDROID_HOME/tools/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH

Após salvar, aplique as mudanças:

    source ~/.zshrc

Verifique se as variáveis foram aplicadas corretamente:

    echo $ANDROID_HOME
    adb --version

A saída do echo deve mostrar o caminho do SDK.
A saída do adb deve mostrar a versão do Android Debug Bridge.


CRIANDO UM EMULADOR (AVD) PARA TESTES
--------------------------------------------------------------------------------
1. No Android Studio, acesse:
   Device Manager → Create Device (ícone "+" no canto superior)

2. Selecione o hardware:
   - Escolha um modelo de dispositivo (ex: Pixel 7)
   - Clique em Next

3. Selecione a imagem do sistema:
   - Para M1/M2: selecione imagens com arquitetura ARM64 ou Apple Silicon
   - Recomendado: Android 13 (API 33) ou Android 14 (API 34)
   - Clique em Download caso a imagem não esteja instalada
   - Clique em Next

4. Revise as configurações e clique em Finish.

5. Inicie o emulador pelo botão Play (▶) no Device Manager.

Verifique se o Appium reconhece o emulador rodando:

    adb devices

A saída deve listar o emulador com status "device".


VERIFICAÇÃO FINAL PARA O APPIUM
--------------------------------------------------------------------------------
Com o emulador rodando, execute o diagnóstico do Appium:

    appium driver doctor uiautomator2

Todos os itens em verde (✔) indicam que o ambiente Android está pronto
para ser utilizado com o Appium e CodeceptJS.
