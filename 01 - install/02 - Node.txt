NODE.JS - INSTALAÇÃO VIA NVM (Apple Silicon M1/M2)
================================================================================

O QUE É O NVM
--------------------------------------------------------------------------------
NVM (Node Version Manager) é o gerenciador de versões do Node.js. É a forma
recomendada de instalação pois permite trocar de versão facilmente, o que é
essencial em projetos de automação com CodeceptJS + Appium.


⚠️  LEIA ANTES DE COMEÇAR
--------------------------------------------------------------------------------
  - NUNCA instale o Node diretamente via brew install node sem o NVM.
    Isso remove a flexibilidade de trocar versões quando necessário.
  - Caso o comando nvm não seja reconhecido após a instalação, verifique se
    as linhas do NVM foram adicionadas ao ~/.zshrc e execute source ~/.zshrc.
  - Versões recomendadas para este projeto: Node 18 LTS ou Node 20 LTS.
    Versões mais antigas podem causar incompatibilidades com o CodeceptJS
    e o Appium.


VERIFICAR SE JÁ ESTÁ INSTALADO
--------------------------------------------------------------------------------
    nvm --version
    node -v

Se retornarem versões, o NVM e o Node já estão instalados. Pule para a seção
de verificação ao final deste documento.


INSTALAÇÃO DO NVM
--------------------------------------------------------------------------------
Cole o comando abaixo no Terminal e pressione ENTER:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash

Após a instalação, recarregue o terminal:

    source ~/.zshrc


INSTALAÇÃO DO NODE.JS LTS
--------------------------------------------------------------------------------
    nvm install --lts
    nvm use --lts
    nvm alias default node


VERIFICAÇÃO
--------------------------------------------------------------------------------
    node -v       (esperado: v18.x ou v20.x)
    npm -v        (esperado: 10.x)
    nvm --version (esperado: 0.40.x)
