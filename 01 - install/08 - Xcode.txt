================================================================================
XCODE - INSTALAÇÃO E CONFIGURAÇÃO PARA APPIUM (Apple Silicon M1/M2)
================================================================================

O QUE É O XCODE
--------------------------------------------------------------------------------
Xcode é a IDE oficial da Apple para desenvolvimento iOS e macOS. Para automação
mobile com Appium, o Xcode é obrigatório pois fornece:
  - Os simuladores de iPhone e iPad utilizados nos testes
  - O XCUITest framework, base do driver xcuitest do Appium
  - O WebDriverAgent (WDA), componente instalado nos dispositivos para
    receber e executar os comandos do Appium
  - As Command Line Tools necessárias para compilação e build


⚠️  LEIA ANTES DE COMEÇAR
--------------------------------------------------------------------------------
  - O Xcode ocupa bastante espaço em disco. Reserve ao menos 30 GB livres
    considerando o Xcode, as Command Line Tools e os simuladores antes
    de iniciar o download.
  - É necessário ter um Apple ID para baixar o Xcode pela App Store.
    Para testes em dispositivos físicos, é recomendado ter uma conta no
    Apple Developer Program (https://developer.apple.com).
  - Para testes em dispositivo físico iOS, o WebDriverAgent precisa ser
    assinado com uma conta de desenvolvedor válida. Sem assinatura, os
    testes só funcionam em simuladores.
  - Sempre mantenha o Xcode atualizado. Versões muito antigas podem ser
    incompatíveis com o driver XCUITest mais recente do Appium.
  - O Xcode só roda em macOS — esta etapa não se aplica a ambientes
    Windows ou Linux.
  - Versões recomendadas de iOS para testes com Appium: iOS 16 ou superior.


INSTALAÇÃO DO XCODE
--------------------------------------------------------------------------------
1. Abra a App Store no seu Mac.

2. Pesquise por "Xcode" e clique em "Obter" / "Get".

3. Aguarde o download — o Xcode é um arquivo grande (aproximadamente 15 GB).
   Certifique-se de ter espaço em disco disponível.

4. Após a instalação, abra o Xcode pela primeira vez:
   - Aceite os termos de licença quando solicitado
   - Aguarde a instalação dos componentes adicionais


INSTALAÇÃO DAS COMMAND LINE TOOLS
--------------------------------------------------------------------------------
Após instalar o Xcode, instale as ferramentas de linha de comando:

    xcode-select --install

Aceite os termos de licença do Xcode via Terminal:

    sudo xcodebuild -license accept

Verifique o caminho das ferramentas instaladas:

    xcode-select -p

A saída esperada:
    /Applications/Xcode.app/Contents/Developer


CONFIGURANDO SUA CONTA DE DESENVOLVEDOR NO XCODE
--------------------------------------------------------------------------------
Para testes em dispositivos físicos, adicione sua conta Apple ao Xcode:

  1. Abra o Xcode
  2. Acesse: Xcode → Settings → Accounts (ou Preferences → Accounts)
  3. Clique no "+" e selecione "Apple ID"
  4. Faça login com seu Apple ID
  5. Verifique se o "Personal Team" ou seu time de desenvolvimento está listado


INSTALANDO SIMULADORES iOS
--------------------------------------------------------------------------------
Para baixar simuladores de iPhone e iPad:

  1. No Xcode, acesse: Xcode → Settings → Platforms
  2. Clique no "+" para adicionar uma nova plataforma iOS
  3. Selecione a versão do iOS desejada e aguarde o download
  4. Mantenha ao menos a versão mais recente disponível instalada

Para listar os simuladores disponíveis via Terminal:

    xcrun simctl list devices

Para abrir o Simulator diretamente:

    open -a Simulator


HABILITANDO MODO DESENVOLVEDOR EM DISPOSITIVOS FÍSICOS iOS
--------------------------------------------------------------------------------
Para testes em dispositivo físico:

  1. Conecte o iPhone/iPad ao Mac via cabo USB
  2. No dispositivo, acesse: Ajustes → Privacidade e Segurança → Modo Desenvolvedor
  3. Ative o "Modo Desenvolvedor" e reinicie o dispositivo quando solicitado
  4. Após reiniciar, confirme a ativação do Modo Desenvolvedor
  5. No Mac, abra o Xcode → Window → Devices and Simulators
  6. Confirme "Trust" no dispositivo quando solicitado pelo Mac
  7. Aguarde a instalação dos componentes de suporte no dispositivo


INSTALAÇÃO DE FERRAMENTAS OPCIONAIS RECOMENDADAS PARA O APPIUM
--------------------------------------------------------------------------------
Ferramentas adicionais que melhoram a experiência com o driver XCUITest:

  ffmpeg (gravação de vídeo dos testes):
    brew install ffmpeg

  Carthage (dependências opcionais do XCUITest):
    brew install carthage

  xcpretty (melhora a leitura dos logs do Xcode):
    gem install xcpretty


VERIFICAÇÃO FINAL PARA O APPIUM
--------------------------------------------------------------------------------
Com o Xcode instalado e configurado, verifique o ambiente iOS do Appium:

    appium driver doctor xcuitest

Todos os itens em verde (✔) indicam que o ambiente iOS está pronto
para ser utilizado com o Appium e CodeceptJS.

Para confirmar que o simulador é reconhecido pelo Appium:

  1. Inicie um simulador pelo Xcode ou pelo comando:
     open -a Simulator

  2. Em outro Terminal, verifique:
     xcrun simctl list devices | grep Booted

  A saída deve mostrar o simulador com status "Booted".
